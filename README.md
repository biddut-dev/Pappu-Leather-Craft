# Pappu Leather Craft — E-Commerce Platform

A production-ready e-commerce platform for **Pappu Leather Craft**, handcrafted leather footwear & leather accessories brand in Bangladesh.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Dark Editorial Tokens
- **Icons**: Lucide Icons
- **Motion**: Framer Motion
- **Database**: MongoDB & MongoDB Atlas (with resilient zero-config fallback)
- **Authentication**: JWT Session in secure HTTP-only cookies + bcryptjs password hashing
- **Currency**: Bangladeshi Taka (BDT `৳`)

## Running Locally

1. Install dependencies (already installed):
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
